Detailed Description

Settings for the volume of the different DCOs. A single "tone" consists of mixing all DCOs together. With this setting you can define of the ratios. Used for saving/loading patches (see PatchSetting)

Remarks
{Note: Due to the nature of how teensy handles volume all volumes added shouldn't exceed 1, else distortion is highly probable}
